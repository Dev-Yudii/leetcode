# LeetCode Solutions
My personal LeetCode Daily Challenge solutions, one Python file per problem.

Files are generated by an external automation pipeline and solved here, in the open, one day at a time.


## Layout
Each solution file follows the same shape:

```python
"""
This problem was extracted on <YYYY-MM-DD HH:MM (UTC offset)> from LeetCode at <link>.
You can check the full problem description there.
Problem Title:
    ...
Difficulty:
    ...
Tags:
    ...
"""

class Solution:
    ...

if __name__ == "__main__":
    # local test runs with examples parsed from the problem
    ...

"""
Notes:
    - ...
"""
```

- Files live under the first topic's folder as `{ID}_{slug}.py`.
- The header records when the problem was fetched and links back to the original statement — the full description lives on LeetCode, not here.
- `Notes:` at the bottom is where I leave thoughts from the solving session.


## Solution Workflow
1. Open the daily file in any Python 3 environment (e.g. VS Code).
2. Solve inside `class Solution`, running the local `__main__` tests as you go.
3. Do the full submission, with all test cases, on [LeetCode](https://leetcode.com).
4. Commit the solved file here.
